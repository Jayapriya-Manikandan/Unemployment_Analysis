# 📊 Unemployment Analysis in India

An interactive data analysis and visualization project that explores unemployment trends, regional patterns, employment levels, labour participation, and the impact of COVID-19 in India.

## 📌 Project Overview

This project analyzes unemployment data in India using Python and presents the findings through an interactive multi-page Streamlit web application.

The application allows users to explore unemployment trends over time, compare different regions, analyze urban and rural areas, examine employment and labour participation, and understand changes during the COVID-19 period.

## 🎯 Project Objectives

- Analyze unemployment trends over time
- Compare unemployment rates across regions
- Study estimated employment levels
- Analyze labour participation rates
- Compare urban and rural unemployment
- Examine unemployment patterns during the COVID-19 period
- Present findings using interactive visualizations
- Build an easy-to-use data analysis dashboard

## 📂 Dataset

The project uses the **Unemployment in India** dataset.

### Dataset Columns

- `Region`
- `Date`
- `Frequency`
- `Estimated Unemployment Rate (%)`
- `Estimated Employed`
- `Estimated Labour Participation Rate (%)`
- `Area`
